# Tabla de sustituciones — Marcas IA en español

Cheatsheet de reemplazos para los conectores, palabras y patrones más característicos del texto generado por IA en español. Útil tanto con la skill como en revisión manual.

---

## Tier 1 — Conectores formulaicos

| Conector IA | Alternativas naturales | Notas |
|---|---|---|
| "Es importante destacar que" | Integrar directamente en la oración | "La clave aquí es que", "Lo que vale la pena señalar es que", o simplemente suprimir |
| "Además" (inicio de párrafo) | "Y también", "Sumado a esto", punto y aparte sin conector | Si la idea fluye, no necesita conector |
| "Por otro lado" | "Ahora bien", "Dicho esto", "Eso sí", punto y aparte | |
| "Sin embargo" (inicio de párrafo) | "Pero", "Claro que", "Con todo", integrar con coma | "Sin embargo" en mitad de oración es aceptable |
| "En conclusión" | "A fin de cuentas", "En definitiva", "Dicho todo esto", reformular sin anunciarlo | Evitar anunciar la conclusión; dejar que fluya |
| "Es fundamental que" | Integrar en la oración como afirmación directa | "Las organizaciones deben..." en lugar de "Es fundamental que las organizaciones..." |
| "Cabe mencionar que" | Suprimir y afirmar directamente | |
| "Cabe destacar que" | Suprimir y afirmar directamente | |
| "Por lo tanto" | "Así que", "De ahí que", "Por eso", integrar con coma | |
| "En consecuencia" | "De ahí", "Por eso mismo", punto y seguido | |
| "Hoy en día" | "Actualmente", "Hoy", suprimir si el contexto lo implica | |
| "Vale la pena señalar que" | Suprimir o reformular como afirmación directa | |
| "Del lado positivo" | Reformular integrando el matiz positivo en la oración | |
| "Permíteme explicarte" | Suprimir — explicar directamente | |
| "Como se puede ver" | Suprimir | |
| "Es evidente que" | Suprimir o reformular | Si es evidente, no hace falta decirlo |
| "En general" (inicio de párrafo) | Integrar al final de oración o suprimir | En mitad de oración es aceptable |

## Tier 3 — Patrones estructurales

| Patrón IA | Cómo romperlo |
|---|---|
| Agrupamiento en tríos ("rápido, fiable y escalable") | Usar solo dos elementos o reformular como oración | "Rápido y fiable, con capacidad de crecer según la demanda" |
| "poder + infinitivo" repetido ("puede ayudar", "podría ser", "puede resultar") | Usar afirmaciones directas o variar con subjuntivo | "Ayuda a", "resulta", "sirve para" |
| Estructura "definición → importancia → tipos → conclusión" | Empezar por el problema, el ejemplo o la consecuencia | Invertir el orden clásico deductivo |
| Todos los párrafos de longitud similar | Introducir un párrafo muy corto (1-2 oraciones) entre dos largos | |
| Cadena de adverbios en "-mente" | Conservar solo uno; reformular los demás | "Claramente, obviamente y definitivamente" → "Está claro, y no hay vuelta de hoja" |

## Tier 4 — Guiones largos (—)

| Uso del guión largo | Sustitución |
|---|---|
| Inciso o aclaración — como esta — | Paréntesis: (como esta) |
| Consecuencia o conclusión — por eso | Coma: , por eso |
| Enumeración tras dos puntos — elemento 1 — elemento 2 | Reformular como oración o usar coma |

## Marcadores discursivos del español para usar

Expresiones que los modelos de IA raramente producen de forma espontánea y que dan naturalidad al texto:

| Función | Expresiones |
|---|---|
| Matizar o puntualizar | "eso sí", "ahora bien", "claro que", "eso no quita que" |
| Introducir perspectiva | "la verdad es que", "hay que decirlo", "en el fondo" |
| Concluir con naturalidad | "a fin de cuentas", "en definitiva", "dicho esto" |
| Ejemplificar | "sin ir más lejos", "y no es un caso aislado" |
| Marcar relevancia | "ahí está la clave", "y no es un detalle menor", "vale la pena detenerse aquí" |
| Contrastar con suavidad | "dicho esto", "con todo", "aunque hay que matizarlo" |
| Transiciones imperfectas | "por cierto", "volviendo al tema", "aunque esto es otro asunto" |
